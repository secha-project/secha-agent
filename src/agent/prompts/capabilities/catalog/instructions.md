Use the catalog capability to discover and inspect schema metadata.

- Browse tables when a table name is unknown, ambiguous, or possibly misspelled.
- Search columns when the user describes a column in human language or its exact identifier is unknown.
- Use metadata tables, when available, to resolve uncertain device identifiers.
- Describe tables only after their identifiers are known.
- Treat canonical names returned by catalog tools as authoritative; do not invent identifiers.
