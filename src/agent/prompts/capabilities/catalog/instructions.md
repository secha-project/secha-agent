## Catalog capability

Use the catalog capability to discover and inspect schema metadata.

- Browse tables when a table name is unknown, ambiguous, or possibly misspelled.
- Find columns when the user describes a column in human language or its exact identifier is unknown. This searches column names and metadata only, never table data or row values.
- Use metadata tables, when available, to resolve uncertain device identifiers.
- Describe tables only after their identifiers are known.
- Catalog tools cannot search or filter row data. Use the query capability when data values are needed.
- Treat names returned by catalog tools as authoritative; do not invent identifiers.
